# Project Structure

```text
movieLens-content-analysis/
├── code/       # day-by-day executable scripts and run notes
├── sql/        # DuckDB SQL source and analysis queries
├── portfolio/  # project materials, data dictionary, and resume drafts
└── README.md
```

The raw MovieLens dataset, generated reports, model weights, and local database are intentionally excluded from the repository. Source code remains under `code/` and `sql/`.
